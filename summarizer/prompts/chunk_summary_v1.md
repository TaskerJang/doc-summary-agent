# 작업 (Task)
아래 금융 문서 섹션을 읽고 핵심 내용을 불릿 포인트로 요약하세요.
수치 데이터가 있으면 차트 스펙(chart_spec)도 함께 구조화하여 반환하세요.

# 입력
섹션명: {section}

내용:
{text}

# 제약사항 (Constraints)
- 불릿 포인트 2~5개로 요약하세요.
- 각 불릿은 1~2문장으로 작성하세요.
- 문서에 없는 내용은 절대 생성하지 마세요.
- 수치(금액, 비율, 날짜)는 원문 그대로 사용하세요. 단위(조, 억, %, %p)를 생략하거나 변환하지 마세요.
- 섹션 내용이 면책고지·법적고지·광고성 문구이면 bullets를 빈 배열([])로 반환하세요.
- ~~ 기호를 절대 사용하지 마세요. 범위 표현은 "~"(물결표 하나) 또는 "에서"를 사용하세요. (예: 3.0~3.5개월, 2~3분기)

# 표(Table) 처리 규칙
섹션 내용에 표가 포함된 경우 아래 규칙을 반드시 따르세요.

1. **헤더 우선 파악**: 표의 첫 행(컬럼명)을 먼저 읽어 각 컬럼이 무엇을 의미하는지 파악하세요.
   - 예: `| 구분 | 4Q24 | 1Q25 | 2Q25 | 3Q25 | 4Q25 | 24 YTD | 25 YTD |` 형태면
     각 열이 분기 또는 연간 누적임을 인식하세요.
2. **컬럼-값 대응 유지**: 각 행의 수치를 반드시 해당 컬럼 헤더와 함께 기술하세요.
   - 올바른 예: "세전이익: 4Q25 765.9십억원, 25 YTD 2,079.4십억원"
   - 잘못된 예: "세전이익은 765.9이다" (어느 기간인지 불명확)
3. **YTD vs 분기 구분**: YTD(연간 누적)와 분기(QoQ) 수치를 혼동하지 마세요.
   - YTD 컬럼이 있으면 연간 합산 수치임을 명시하세요.
4. **구조가 깨진 표**: 표 구조가 불완전하더라도 수치와 항목명이 존재하면 파악 가능한 범위에서 요약하세요.
   단, 컬럼 귀속이 불확실한 수치는 "(기간 불명확)"으로 표시하세요.

# chart_spec 생성 규칙

**STEP 1 — 차트화 인사이트 판단 (내부 판단, 출력 불필요)**
chart_spec을 작성하기 전에 다음 질문에 스스로 답하세요:
> "이 데이터를 차트로 보여줬을 때 독자가 텍스트 요약보다 더 빠르게 파악할 수 있는 인사이트가 있는가?"

- 인사이트가 명확하다 → chart_spec 작성 진행
- 인사이트가 불분명하다 (기간·단위·항목 맥락이 부족해 오해를 유발할 수 있다) → chart_spec을 null로 반환

**STEP 2 — chart_spec 작성**

수치 데이터(3개 이상)가 있고 STEP 1 판단이 "인사이트 명확"인 경우에만 작성하세요.

**chart_type 판단 기준:**
- 시계열 추이 (연도·분기별 변화) → `"line"`
- 항목 간 크기 비교 (사업부·지역·상품별 등락률·순매수 등) → `"bar"`
- 단계별 누적·차감 (매출→영업이익→순이익 흐름) → `"waterfall"`
- 구성 비율 (%) → `"pie"`
- 수치 2개 이하 또는 차트화 부적합 → `"none"` (chart_spec 전체를 null로)

**financial noise 방지 — labels 필수 규칙:**
- labels에 반드시 연도·분기·기간 컨텍스트를 포함할 것
- ❌ 금지: `["영업이익", "순이익", "매출"]` (기간 없는 항목명 단독 나열, 맥락 없는 종목명 단순 나열)
- ✅ 허용: `["2022", "2023", "2024"]` / `["2024Q1", "2024Q2", "2024Q3"]` / `["국내", "해외", "기타"]` / 등락률 비교 시 종목명 단독 허용
- 비율(pie) 차트는 항목명 단독 labels 허용

**values 규칙:**
- 숫자만 포함 (단위 제거). 단위는 unit 필드에 별도 기재
- ❌ 금지: `["1,234억원", "2,100억"]`
- ✅ 허용: `[1234, 2100]` + `"unit": "억원"`

**title 규칙:**
- title은 차트 내용을 간결하게 표현하는 한국어 문장으로 작성하세요.
- "(기간 불명확)", "(지표 불명확)", "(기간/지표 불명확)" 등 불확실성을 나타내는 괄호 표현을 title에 포함하지 마세요.
- 기간이 불분명한 경우 기간 표현 자체를 생략하고 내용 중심으로 작성하세요.
- ❌ 금지: `"항목별 수치(기간 불명확)"` / `"종목별 수치(기간/지표 불명확)"`
- ✅ 허용: `"항목별 수치 비교"` / `"종목별 등락률"` / `"기관 순매수 상위 종목"`

# 출력 형식 (Output)
반드시 아래 JSON 형식으로만 반환하세요. JSON 외 다른 텍스트는 포함하지 마세요.

{{"section": "섹션명", "bullets": ["불릿1", "불릿2"], "source": "섹션명", "chart_spec": {{"chart_type": "line", "title": "차트 제목", "labels": ["2022", "2023", "2024"], "values": [100, 120, 150], "unit": "억원"}}}}

수치 데이터가 없거나 STEP 1 판단이 "인사이트 불분명"인 경우:
{{"section": "섹션명", "bullets": ["불릿1", "불릿2"], "source": "섹션명", "chart_spec": null}}
