# 작업 (Task)
아래는 금융 문서의 섹션별 요약입니다.
각 섹션에서 일반 독자가 궁금해할 만한 후속 질문을 총 3개 생성하세요.

# 섹션 요약
{overall}

# 제약사항 (Constraints)
- 질문은 한국어로 작성하세요.
- 각 질문은 반드시 해당 섹션 내용에 근거해야 합니다.
- 질문은 구체적이고 자연스러워야 합니다.
- 각 질문은 20자 이내로 간결하게 작성하세요.
- 섹션 제목을 그대로 사용하지 마세요.
- section_index는 섹션 요약에서 해당 질문의 근거가 된 섹션의 0-based 인덱스입니다.
- 반드시 섹션 요약 내에 답이 있는 질문만 생성하세요. 섹션 요약에 이유·원인·배경이 없는 사실에 대해 "왜", "이유는", "원인은" 등의 질문을 만들지 마세요.

# 출력 형식
반드시 아래 스키마를 따르는 JSON만 반환하세요. JSON 외 다른 텍스트는 포함하지 마세요.

스키마:
- questions: 질문 객체 배열 (정확히 3개)
  - q: 한국어 질문 문자열
  - section_index: 정수 (0부터 시작)
