# 작업 (Task)
아래는 금융 문서의 전체 요약입니다.
금융·투자 전문가가 실제 의사결정에 활용할 수 있는 심층 후속 질문을 총 3개 생성하세요.

# 전체 요약
{overall}

# 질문 생성 원칙
- **문서 근거 필수**: 요약에 답이 명시적으로 존재하는 내용에 대해서만 질문을 만드세요.
- **분석적 질문**: 단순 수치 확인이 아니라 인과관계·영향·배경·시사점을 묻는 질문을 만드세요.
  - 좋은 예: "중동 지정학 리스크가 반도체 섹터에 미치는 영향은?"
  - 나쁜 예: "외국인 순매도 규모는 얼마인가요?" (단순 수치 조회)
- **교차 분석**: 가능하면 문서 내 두 가지 이상의 이슈를 연결하는 질문을 포함하세요.
  - 예: "고유가와 연준 금리 인하 기대 축소가 동시에 발생할 때 포트폴리오 전략은?"
- **투자 관점**: 수혜·피해 업종, 리스크 요인, 전략적 시사점을 묻는 질문을 선호하세요.

# 제약사항 (Constraints)
- 질문은 한국어로 작성하세요.
- 질문은 구체적이고 자연스러운 완전한 문장 형태여야 합니다.
- 각 질문은 15자 이상 40자 이내로 작성하세요.
- 섹션 제목을 그대로 사용하지 마세요.
- 요약에 이유·원인·배경이 명시되지 않은 사실에 대해 "왜", "이유는", "원인은" 등의 질문을 만들지 마세요.
- 단순히 수치를 묻거나 사실을 나열하는 질문은 만들지 마세요.
- 문서의 신뢰도나 정확성을 묻는 질문은 만들지 마세요.
- section_index는 해당 질문의 근거가 된 섹션의 0-based 인덱스입니다.

# 출력 형식
반드시 아래 스키마를 따르는 JSON만 반환하세요. JSON 외 다른 텍스트는 포함하지 마세요.

스키마:
- questions: 질문 객체 배열 (정확히 3개)
  - q: 한국어 질문 문자열
  - section_index: 정수 (0부터 시작)
