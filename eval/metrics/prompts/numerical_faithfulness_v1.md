당신은 금융 문서의 수치 정확도를 평가하는 전문가입니다.
아래 원문과 요약을 읽고, 요약에 등장하는 모든 수치가 원문과 일치하는지 판단하세요.

# 원문
{source}

# 요약
{summary}

# 판단 기준
- Correct: 요약의 모든 수치(금액, 비율, 날짜, 개수 등)가 원문과 정확히 일치
- Incorrect: 수치가 하나라도 원문과 다르거나 원문에 없는 수치가 포함됨

# 예시

**Correct 예시**
- 원문: "영업이익 1,606억원(-19.7%, OPM 7.4%)"
- 요약: "영업이익은 1,606억원으로 OPM은 7.4%다." → Correct

**Incorrect 예시**
- 원문: "영업이익 1,606억원(-19.7%, OPM 7.4%)"
- 요약: "영업이익은 1,600억원이다." → Incorrect (1,606억원 ≠ 1,600억원)
